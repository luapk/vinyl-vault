# Brand: how the logos are made

Everything in `public/logo-*.svg` is generated by the scripts here. Nothing in
that directory should be hand-edited: the next run overwrites it.

This exists because for a while it did not. The logos were produced by scripts
that lived outside the repo, so the files in `public/` were the only artefact
and recolouring one, changing the subline, or exporting a new lockup meant
rebuilding the whole toolchain from memory. That is a bad position for a
trademark filing and a worse one for a handover.

## Regenerating

```bash
python3 -m pip install fonttools      # the only dependency
python3 brand/stamp.py                # -> public/logo-stamp-*.svg, logo-mark-*.svg
python3 brand/stacked.py              # -> public/logo-block-*.svg
python3 brand/stacked.py --variants   # also writes the auditioned alternatives here
```

Both scripts are deterministic. Running them against an unchanged checkout
reproduces all nine files in `public/` byte for byte, which is the check to
run after touching anything in this directory.

## The three lockups

| File | Script | Aspect | Used by |
| --- | --- | --- | --- |
| `logo-block-*.svg` | `stacked.py` | 1.33:1 | the app header (`BLOCK`) |
| `logo-stamp-*.svg` | `stamp.py` | 2.77:1 | footer, auth, pricing (`STAMP`) |
| `logo-mark-*.svg` | `stamp.py` | 3.90:1 | the static legal pages (`STAMP_MARK`) |

`stamp.py` builds the horizontal lozenge: the wordmark on one line, with the
subline under it for the full stamp and omitted for the mark. `stacked.py`
builds FOUND over SOUND inside a rounded keyline.

Colourways are `acid` `#CAFE04`, `black` `#0D0C0A`, `white` `#F7F8F2`. An
`<img>` cannot inherit `currentColor`, so each colour is a separate file and
the call site picks one rather than theming it.

## Why the stacked lockup works

FOUND and SOUND are five letters each and differ only in the first. At matched
cap height they measure 2605.5 and 2644.2 units, 2.5% apart, so they stack into
very nearly a rectangle.

That 2.5% has to go somewhere, and `block(width_matched=)` is the switch:

- `True` scales FOUND up so the two edges sit flush, costing about 1px of cap
  height in 40. This is what ships. A flush edge reads as deliberate where a
  2.5% rag reads as a mistake.
- `False` keeps cap heights identical and centres both, which is the
  typographically pure reading and leaves a 1.2% rag a side.

## The subline is outlines, on purpose

`outline_text` converts it from Hanken Grotesk with fontTools rather than
setting it as live text, so the logo never waits on a webfont, cannot reflow if
one fails to load, and carries no font licence into a trademark filing.

Its tracking is capped at `MAX_TRACK_EM` (0.42). The rule is that the subline
fills the lozenge's measure so the two parts read as one block, but uppercase
stops reading as a phrase much past 0.42em, and "YOUR VINYL, SORTED" is short
enough that filling this measure would need over 1em. So the cap wins and the
line is centred instead. Filling the measure is worth having; it is not worth
illegibility.

## What is NOT reproducible from this directory

`traces/found.svg` and `traces/sound.svg` are potrace output from the original
artwork, and **the artwork itself is not in this repo**. Those two files are
therefore the source of truth for the letterforms, not a derived artefact. If
they are lost, the letterforms have to be re-traced from the original brand
sheet.

The trace deliberately does not reproduce the printed grain in the original:
tracing speckle produces hundreds of stray islands that read as dirt at small
sizes and bloat the file. If the distressed look is ever wanted for print, it
belongs as a texture overlay on top of this clean vector, never baked into the
outline.

## One known inconsistency

The acid in the original artwork measures `#B3DF04` across 663,000 pixels of
flat ground. The app uses `#CAFE04`, a brighter yellow-green, and so do these
generated files. That is a real difference and not JPEG noise. It has not been
reconciled; the app is the easier of the two to change if it ever should be.
